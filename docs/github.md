# Jak wrzucić aplikację na GitHub (raz, ok. 10 minut)

1. **Konto GitHub**: załóż na https://github.com (jeśli nie masz).
2. **Połącz GitHub z Claude**: wejdź na https://claude.ai/connect-github i zaloguj się.
   Gdy zapyta o dostęp do repozytoriów, wybierz „All repositories” albo później wybierz `poliglota`.
3. **Nowe repozytorium**: na GitHubie kliknij **+** (prawy górny róg) → **New repository**.
   Nazwa: `poliglota`. Zaznacz **Private**. NIE dodawaj README. Kliknij **Create repository**.
4. **Napisz Claude'owi** nazwę: `twój-login/poliglota`. Claude wyśle kod.
5. **Włącz stronę**: w repozytorium → **Settings** → **Pages** → „Source”: **GitHub Actions**.
6. Po ok. 3 minutach aplikacja będzie pod adresem `https://twój-login.github.io/poliglota/`.
   Uwaga: przy prywatnym repozytorium GitHub Pages wymaga płatnego planu. Jeśli go nie masz,
   ustaw repozytorium jako publiczne (kod i frazy będą widoczne, Twoje postępy i nagrania nie – zostają w przeglądarce).
7. **Frazy dla pozostałych języków**: zakładka **Actions** → **Import Tatoeba** → **Run workflow**.

## Na telefonie / iPadzie

Otwórz adres w Brave → menu → „Dodaj do ekranu głównego”. Przy pierwszym ćwiczeniu zezwól na mikrofon.
